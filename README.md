# Arc Folder Preview

Мод для штатного превью свёрнутых папок в **Zen 1.24b** по референсу Arc.

- Ширина панели 240px, скругление 12px, тёмная и светлая темы.
- Поле поиска высотой 48px, строки с равномерным шагом 45px.
- Заголовок 14px, время 12px с обычным начертанием вместо мелкого полужирного текста.
- Иконки 16px, отступ до текста 8px; длинные названия обрезаются многоточием.
- Скрипт убирает повтор названия папки после времени. Язык и сами значения времени остаются штатными.

Наведение, поиск, выбор вкладки, стрелки и Enter обрабатывает Zen.
Мод не переименовывает вкладки, не меняет их порядок и не загружает иконки из сети.
Если у вкладки нет favicon, остаётся стандартная иконка Zen.

## Ручная установка оформления

1. В `about:config` включите `toolkit.legacyUserProfileCustomizations.stylesheets`.
2. Через `about:support` откройте папку профиля Zen.
3. Скопируйте `ArcFolderPreview` в подпапку `chrome` профиля.
4. В начало `chrome/userChrome.css`, перед остальными правилами, добавьте:

   ```css
   @import url("ArcFolderPreview/chrome.css");
   ```

5. Полностью перезапустите Zen. Сверните папку и наведите на неё курсор.

Для появления меню настройка `zen.folders.search.enabled` должна быть включена.
Задержку наведения задаёт штатная `zen.folders.search.hover-delay`.
Пустые папки и папки без скрытых вкладок не показывают меню — это поведение Zen.

Ручной импорт подключает CSS. Без загрузчика JavaScript в подписи останется
название папки после времени. Копирование `.uc.js` само по себе скрипт не запускает.

## Установка через Sine

1. Откройте **Настройки Zen → Sine Mods**.
2. Вставьте ссылку в поле установки из GitHub:

   ```text
   https://github.com/b2theh/ArcFolderPreview
   ```

3. Для скрипта разрешите JavaScript из неофициальных источников в настройках Sine.
4. Установите мод и полностью перезапустите Zen.

В пакете есть `theme.json`, `chrome.css` и `preview.uc.js`.
Для полного оформления подписей нужен Sine с поддержкой JavaScript.

Не подключайте одновременно ручной импорт и тот же мод через Sine.
Для удаления уберите импорт или отключите мод в Sine, затем перезапустите Zen.

## Настройка

В начале `chrome.css` меняются `--arc-folder-width`, `--arc-folder-radius`
и `--arc-folder-row-height`. Панель показывает до шести строк с прокруткой.
Штатный боковой отступ и привязка меню к папке сохранены.
Имена сайтов берутся из названий вкладок; при необходимости переименуйте их в Zen.

## Проверка

### 1.0.2

У самой панели восстановлена непрозрачная заливка: прозрачность внешнего окна
больше не оставляет фон целиком на внутреннем `::part(content)`. Системная рамка
macOS отключена, CSS-контур по-прежнему рисуется только один раз.

Панель и её внутренний слой используют одну цветовую схему панели инструментов
Zen; если переменная схемы отсутствует, применяется системное предпочтение.
Цвета фона, текста, рамки и выделения вычисляются через `light-dark()` и
обновляются средствами CSS при переключении темы, без повторного открытия меню.

Структура панели и штатные стили сверены с установленным Zen. Визуальная
проверка остаётся за пользователем: переключить светлую → тёмную → светлую
тему при открытом превью, затем закрыть и открыть его, повторить после смены
рабочего пространства. Заливка должна оставаться непрозрачной, текст и поиск —
читаемыми. При автоматической теме также проверить смену темы macOS.

### 1.0.1

Убрано наложение системного контура macOS и CSS-рамки: панель рисует
единственный контур с круглыми углами. Подсветка папки сохраняется по штатному
атрибуту `open`, пока открыто её превью, в том числе при переходе курсора в меню.
Фокус ввода остаётся в поиске для работы клавиатуры.

Разметка, селекторы, момент заполнения списка и формат подписи сверены
с исходниками установленного Zen 1.24b. Проверены синтаксис CSS, JavaScript,
JSON и обработка/восстановление подписей на тестовой разметке.
Визуальная проверка остаётся за пользователем: обе темы, длинные названия,
более шести вкладок, поиск, стрелки/Enter и расположение у края окна.
Zen автоматически не запускался.
